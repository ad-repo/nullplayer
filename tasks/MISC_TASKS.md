| M46 | Closing the Equalizer Studio stops the curve that was playing | Reported 2026-10-14; cause read from code, not yet reproduced live. While the Studio is open, playback hears its edit: `EqualizerStudioSession.pushAudition` sets `EQProfileController.audition`, which wins over the track's resolved profile and over the global EQ Profiles toggle. `close()` sets `audition = nil`, so playback drops back to whatever resolves for the current track. That is flat when the track has no assignment, its Off, or EQ Profiles is turned off. The curve you were hearing goes silent whenever any of these is true: the edit is unsaved (the session discards it by design), the profile was saved but never assigned to this track, album or artist, or the profile loaded in the Studio is not the one assigned. Nothing in the Studio says closing will change what you hear. Decide what closing should do, then build it: keep the last heard curve playing until the track changes, offer to save and assign the profile to the playing track when what is heard differs from what resolves, or warn on close. **Done when** closing the Studio after picking or editing a curve never silently changes what is playing. The behaviour in each case (unsaved, saved but unassigned, assigned, profiles off) is written in `user-guide` § *EQ Profiles*, with the matching mechanism in `eq-profiles`. Skills: `eq-profiles`, `user-guide`. |
